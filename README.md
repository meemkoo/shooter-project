# 3100 Template Repository
Differs to WPILib generated template:
* Setup in gradle for [profiling with VisualVM](https://docs.wpilib.org/en/stable/docs/software/advanced-gradlerio/profiling-with-visualvm.html)
* Set up spotless formatter
* Adds a VS Code task for starting VisualVM
* Automatically skips asking for simulation extension
* Various changes to be at spec with LTPM

# Maintaining
Each year a new branch will get made from the last year named that year number. When it is determined by the programming lead and/or a mentor that the template is up to spec enough for the current LTPM version, merge the new year branch into main, making sure to keep the new year branch around in case more changes get made
